#  Frontend (P3)

A starter frontend for the  academic resource retrieval DBMS project.

## Files
- `index.html` — search, upload, and moderation page structure
- `style.css` — layout and responsive styles
- `script.js` — sample search data, filters, demo submission and moderation

## Run it
1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and select **Open with Live Server**.

You can also open `index.html` directly in a browser for this demo.

## Important: demo vs connected project
This version works with sample data in the browser. It does not yet read/write the PostgreSQL database. Before the final project demo, coordinate with P2 to replace the demo behavior with actual API calls and agree on endpoint names and JSON fields.

The resource links beginning with `example.com` are placeholders. Replace them with real approved Drive/resource links when the team provides the dataset.
